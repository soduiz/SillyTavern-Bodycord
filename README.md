# 生理孕育状态面板 · Bodycord

给 SillyTavern 加一个**会自己记事的身体**。

聊到几百楼的时候，主模型就开始记不清了：月经什么时候来的、排卵窗口还剩几天、到底怀没怀孕、孕期走到第几周、肚子里的孩子是什么种族、父亲是谁、身上那些痕迹还在不在。它要么忘，要么圆，要么前后对不上。

Bodycord 就是替它记这些的。一个**独立的面板**：自己掷骰、自己算数值、自己存档案，打开就能看到这个身体现在到底是什么状态。

它不管剧情往哪走，也不是记忆插件。**它是一台无情的记录机器**：剧情里身体发生了什么，它记下来、算清楚，然后告诉主模型该注意什么。

---

## 面板里有什么

| 看什么 | 内容 |
|---|---|
| 当前状态 | 怀孕 / 经期 / 阶段名 / 进度 |
| 数据项 | 受精判定、胎数、性别、着床天数 |
| 胎儿 | 一行一个孩子：种族、性别、父亲、显隐性 |
| 状态条 | 生理状态、身体状况、近期性行为 |
| 身体敏感带 | 等级与记录 |
| 旁边还挂着 | 日历（日程与提醒）、记录档案（受孕记录 / 成就 / 孩子）、时光机（每一楼当时的面板快照）、随手记等 |

## 它好在哪

**面板不进正文。** 状态文字一个字都不写进聊天记录，正文干干净净。

**数值不靠 AI 现编。** 插件另外调一次 API 专门做状态推演。骰子在插件手里，受精判定、孕期进度、胎儿性别、着床天数都是算出来的。

**一个对象一份档案。** 每个对象各记各的身体数据，不共用数值；数据跟着聊天文件走，换角色卡、开新聊天都不会串。

**关掉的模块，一个 token 都不占。** 不是"发过去叫 AI 忽略"，是根本不写进去。

**该让主模型知道的，才让它知道。** 推演的结论分两路：一路填进面板，一路只挑"会影响正文怎么写"的部分注入过去（比如"已经怀孕，但角色自己还不知道"），其余细节主模型一个字都看不到。

## 它由什么组成

每次 AI 回复完：掷骰 → 调插件自己的 API 推演状态 → 分成两路。

### 发给主 API 的（影响 AI 怎么演、怎么写）

| 模块 | 作用 |
|---|---|
| 身体补丁（生理设定） | 这个身体的基础设定 |
| 生理期体质补丁 | 经期怎么演 |
| 泌乳体质补丁 | 泌乳怎么演 |
| 孕期母体反应（现实向 / 二次元向，二选一） | 孕期怎么演 |
| 孕期表现适配原则 | 症状轻重怎么定 |
| 角色认知边界 | 防止角色变 B 超机，谁该看出来谁不该 |
| 经期其他角色反应 | 防止所有角色对经期做出雷同反应 |
| 身体痕迹与恢复追踪 | 吻痕、指痕等体表痕迹 |
| 意识状态演化 | 角色知不知道怀孕 |
| 敏感带设定与等级 | 开关打开时才注入 |
| **本轮身体状态摘要** | 怀孕状态 / 月经状态 / 胎儿 / 泌乳 / 敏感带等级 / 致孕方…… |

### 只发给插件自己的 API 的（只影响面板文字）

核心监测系统、生理周期模块、怀孕判定模块、**精子与受精描写**、多致孕方与异卵异父、异种扩展包、血脉遗传特质、生理期系统、身体敏感带记录、泌乳与产后系统。

**这些主 API 一个字都看不到**，所以正文里不会出现「计算说明」「数据项二」这类东西。

### 关掉的模块 = 零注入

不是「注入了叫 AI 忽略」，而是**根本不写进去**，一个 token 都不占。而且已经存下来的值也会跟着清掉（面板上回到「未加载」），不会留着旧值继续发给主 API。

## 它有哪些开关

**追踪对象**四种模式：仅追踪 `{{user}}` / 仅追踪指定的一位角色 / 追踪指定的多位角色 / 自动给新出现的角色建档。每个对象一份独立档案。

**自动门控**（省 token）：带「自动」徽章的补丁只在条件满足时才发出去。

| 门控 | 管哪些补丁 | 什么时候才发 |
|---|---|---|
| 经期相关 | 生理期系统、生理期体质补丁、经期其他角色反应 | 正在来月经 |
| 孕期相关 | 孕期母体反应、角色认知边界、意识状态演化、多致孕方、血脉遗传特质 | 已经怀孕 |
| 周期模块休眠 | 生理周期模块 | 还没怀孕 |
| 受孕流程 | 怀孕判定模块 | 受精那刻起 → 生完恢复为止 |
| 精子描写 | 精子与受精描写 | 体内还有精子，或已怀孕 |

关掉某一条门控 = 那一类补丁永远发送。

**字段开关**：每个字段都能单独关。关掉之后四件事一起生效：推演不再需要它（省输出 token）、上一轮状态里也不带它、面板上不显示、发给主 API 的摘要里不出现。

**补丁**可以按对象分开写（对象级覆盖全局），有数值的补丁字段直接嵌在卡里。互斥的模块同时打开会在页首给出警告。

**呈现方式**：面板可以只用悬浮窗、插进聊天、或者两边都有；插进聊天时可以停在聊天区里，也可以贴在最后一条消息下面。收起时会变成一台小手机。

**楼层面板**：每个楼层下面都能挂一份**那一楼当时的状态**（历史快照，不是当前状态）。每一楼可以单独标成「不参与推演」。

**骰子**是一张可增删的清单，自己写骰式也行（`1d100`、`2d6`、`1d100+5`），也能锁定当前这组骰池，推演一直沿用直到解锁。

| 骰子 | 用途 |
|---|---|
| D100_1 | 受精判定 |
| D100_2 | 胎数判定 |
| D100_3 ~ D100_6 | 子1 ~ 子4 的性别 |
| D100_7 | 胎数 ≥ 5 的卵生 / 虫族 / 鱼类的整批性别倾向 |
| D5 | 着床天数（1=6天 … 5=10天） |

已锁定的判定结果（受精成功与否、着床日、胎数、性别、父亲）不会因为骰值变化被推翻。

**插件接口**可以配多套渠道随时切换。也能从酒馆预设导入参数（模型名、温度、max tokens、各种采样、额外请求头 / 体），以及从预设的上百条条目里挑几条打包进插件。

**外观**：面板左下角和聊天里那个 BOT 的头像槽位都能换图，主题能切，悬浮球和面板位置能拖并且记住。

## 它不碰你的东西

- 不改你的酒馆设置，也不会切换你当前启用的预设
- **不会以任何方式改写你的聊天记录**，只在聊天文件里存自己那一份数据
- 不替别的插件改配置；对方没有公开接口的事，它到这儿就停

## 数据存在哪

- **状态数据**：当前聊天的 metadata 里，跟着聊天文件走。换角色卡、开新聊天都不会串。
- **骰值**：也按聊天独立，这个聊天掷出来的数字不会带到别的聊天去。
- **骰子清单**（有哪些骰子）：全局设置，所有聊天共用一份。
- **设置**（接口、开关、补丁文案、面板位置）：全局，跟着酒馆设置走。
