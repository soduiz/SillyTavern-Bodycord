# 生理孕育状态面板 · Bodycord

给 SillyTavern 加一个**会自己记事的身体**。

聊到几百楼的时候，主模型就开始记不清了：月经什么时候来的、排卵窗口还剩几天、到底怀没怀孕、孕期走到第几周、肚子里的孩子是什么种族、致孕方是谁、身上那些痕迹还在不在。它要么忘，要么圆，要么前后对不上。

Bodycord 就是替它记这些的。一个**独立的面板**：自己掷骰、自己算数值、自己存档案，打开就能看到这个身体现在到底是什么状态。

它不管剧情往哪走，也不是记忆插件。**它是一台无情的记录机器**：剧情里身体发生了什么，它记下来、算清楚，然后告诉主模型该注意什么。

---

## 面板里有什么

| 看什么 | 内容 |
|---|---|
| 当前状态 | 怀孕 / 经期 / 阶段名 / 进度 |
| 数据项 | 受精判定、胎数、性别、着床天数 |
| 胎儿 | 一行一个孩子：种族、性别、致孕方、显隐性 |
| 状态条 | 生理状态、身体状况、近期性行为 |
| 身体敏感带 | 等级与记录 |
| 旁边还挂着 | 日历（日程、提醒、发情日）、记录档案（受孕记录 / 成就 / 孩子）、时光机（每一楼当时的面板快照）、随手记等 |

## 它好在哪

**面板不进正文。** 状态文字一个字都不写进聊天记录，正文干干净净。

**数值不靠 AI 现编。** 插件另外调一次 API 专门做状态推演。骰子在插件手里，受精判定、孕期进度、胎儿性别、着床天数都是算出来的。

**一个对象一份档案。** 每个对象各记各的身体数据，不共用数值；数据跟着聊天文件走，换角色卡、开新聊天都不会串。

**关掉的模块，一个 token 都不占。** 不是"发过去叫 AI 忽略"，是根本不写进去。

**该让主模型知道的，才让它知道。** 推演的结论分两路：一路填进面板，一路只挑"会影响正文怎么写"的部分注入过去（比如"已经怀孕，但角色自己还不知道"），其余细节主模型一个字都看不到。

**不写死人类。** 种族图鉴里每个族有自己的孕期、着床、显怀、胎数、周期长度和生理描写。精灵怀得比人类久、兽形和兽人不是一回事、卵生的不算怀孕，这些都由这一族自己的条目说了算，不是把人类的四十周套到所有人身上。

## 这个版本（2.4）里有什么

**种族图鉴。** 内置 714 个族，从人类、犬猫牛羊到鲸豚、昆虫、神兽，每族四段正文（介绍 / 生理 / 繁殖 / 补充）加一张数值表。绑定一个族，这个人的孕期、着床、显怀、胎数、周期就跟着这个族走。自建、改造、批量停用、批量恢复默认都在图鉴页里做，也能导入导出。

**性特征。** 图鉴里多一批按族写好的解剖描写，默认关着。打开之后只发"这一场里真的有这个族的角色在场"的那几条，同族多人只发一份，文本完全一样的两族会合并成一条发。

**发情期。** 按族设置有没有发情季、一年里哪个时段，日历会把发情日标出来。季节存的是"一年里的位置"而不是月份，所以换一套自定义历法也不会错位。

**产后恢复。** 生完之后有一段时间不排卵，过了恢复日才重新从第 1 天开始算。要几天由这一族的条目决定，也可以全局按三档（轻松 / 现实 / 自定义）统一。默认关。

**交配后排卵。** 兔和猫科不按固定日子排卵，是交配之后才排的。这些族填了诱导排卵率和延迟小时数，插件自己在交配那一下掷。

**泌乳按族。** 图鉴里每一族有一格"泌乳"，可以是有乳腺乳、有嗉囊乳（鸽和企鹅）、无。判断不靠生育方式反推，鸭嘴兽卵生也产奶。

**世界书和角色卡的绑定。** 人物页可以从世界书建角色，也可以直接从角色卡建，建的时候选档位（轻档 / 发情记录 / 正式档，默认轻档）。绑定只存卡名，描述每次现取，你改了卡下一轮就是新内容。

**经期表现。** 经期那几天的流量、颜色、质地、痛经由插件按档位和第几天算出来。页面分「常态」「非常态」两栏，吃了止痛药、受寒这类临时变化会带原因记着，跨天自动清。经期天数在设置里改，上限跟着排卵日走。

## 它由什么组成

每次 AI 回复完：掷骰 → 调插件自己的 API 推演状态 → 分成两路。

### 发给主 API 的（影响 AI 怎么演、怎么写）

| 模块 | 作用 |
|---|---|
| 身体补丁（生理设定） | 这个身体的基础设定 |
| 生理期体质补丁 | 经期怎么演 |
| 泌乳体质补丁 | 泌乳怎么演 |
| 孕期母体反应（现实向 / 二次元向，二选一） | 孕期怎么演 |
| 孕期表现适配原则 | 症状轻重怎么定 |
| 角色认知边界 | 防止角色变 B 超机，谁该看出来谁不该 |
| 经期其他角色反应 | 防止所有角色对经期做出雷同反应 |
| 身体痕迹与恢复追踪 | 吻痕、指痕等体表痕迹 |
| 意识状态演化 | 角色知不知道怀孕 |
| 敏感带设定与等级 | 开关打开时才注入 |
| 种族设定 | 按在场对象绑定的图鉴条目发，同族多人只发一份 |
| 性特征 | 按在场对象发，默认关 |
| **本轮身体状态摘要** | 怀孕状态 / 月经状态 / 胎儿 / 泌乳 / 敏感带等级 / 致孕方…… |

### 只发给插件自己的 API 的（只影响面板文字）

核心监测系统、生理周期模块、怀孕判定模块、**精子与受精描写**、血脉遗传特质、身体敏感带记录、泌乳与产后系统。

**这些主 API 一个字都看不到**，所以正文里不会出现「计算说明」「数据项二」这类东西。

### 关掉的模块 = 零注入

不是「注入了叫 AI 忽略」，而是**根本不写进去**，一个 token 都不占。而且已经存下来的值也会跟着清掉（面板上回到「未加载」），不会留着旧值继续发给主 API。

## 种族图鉴

**三层取值。** 同一个数可能有三处写：个人在参数面板里单独调的值、绑定的那个图鉴条目里的值、全局设置里的默认值。优先级就是从上到下，个人调过就听个人的，没调过听条目的，条目也没写才听全局。

**两层分类。** 第一层是人类 / 动物 / 亚人 / 兽人 / 其他，第二层是种类（猪、牛、狗、鲸豚类这种日常泛称），种类下面才是品种。统称负责兜底和分组，品种才是血统层。

**每个族三份形态。** 兽形、亚人、兽人各一份，品种加进来的时候三份一起加。亚人是人形身体，特征写得克制；兽形按原型来；兽人和亚人一样是人形，只是体型更大。

**孩子由插件掷。** 跨族的两个人，孩子掷到哪一族由插件决定，混血产物（比如人类和精灵的半精灵）写在规则表里，不用你手算。

**名字对不上也不瞎猜。** 角色名对不上任何一个族的时候，插件不会默认他"其实是人类"，而是把最像的六条候选发过去，让你在图鉴页里点一句"用这一条的数据"。它也不会替你借别的族。

**数据是用到才读的。** 七百多条的正文不占启动时间，装好插件先跑起来，读完了再把图鉴页画出来。

## 性特征

一份按族写的解剖描写，只在有该族角色在场时才发。默认关着，因为很多卡自己会写这些，开着容易打架。

条目里分成固定几项和一段自由文字：表面特征、龟头形状、锁结、结节、双阴茎、阴茎骨、泄殖腔、交接方式，加雄性自由描写和雌性的外阴、阴蒂两行。填不出来的格子就留空，留空不等于没有。

亚人和兽人的雌性一律照人类写，兽形才用原型的解剖。亡灵和器灵这类"形状随生前那一族"的，可以在单独调里指定性特征按哪一族走。

## 发情期

图鉴里每一族有一格发情季节，勾上哪几个月就算哪几个月。日历会把发情日标出来，轻档的对象不标。

存的是"一年里的位置"，不是第几月也不是月份名，所以玩家自己换历法、换一年多少天，发情季照样落在该落的地方。闰年多出来那一天也处理过，不会出现"整年一次都没发情"。

## 产后恢复

分娩那一轮进入恢复期，这段时间不排卵、周期冻结，面板上写预计恢复期。到了恢复日，插件把日期写回去，从"第 1 天"重新开始算月经。

要几天看这一族的条目，条目留空就跟全局的三档走（42 天 / 42 到 180 天 / 自定义）。哺乳不会把恢复期往后推，恢复期里怀上了就当场结束恢复期。

## 交配后排卵

兔和猫科的排卵不是按日子来的，是交配之后才排。图鉴里这三格：排卵方式、诱导排卵率、排卵延迟。

触发条件是交配本身，不是内射，戴不戴套、射没射都算这一笔，也不计入受孕风险的账。掷中了才按延迟小时数定排卵日，之后照样走受孕窗口和受精判定。

## 世界书与角色卡

**读世界书一定是你自己点的。** 人物页和设置页渲染的时候一个字都不读，你不点，插件不会去翻你的书。

**从世界书建角色 / 从角色卡建角色。** 建的时候先选档位：轻档只记名字和种族不追踪，发情记录只进发情这一套，正式档才是完整追踪。默认轻档，免得一建就把数据写脏。

**角色描述。** 绑定只存卡名，描述每次现取。改卡立刻生效，卡删了就这一段不发、并在图鉴页报"几张卡找不到"。发出去的只有描述那一段，不带性格、不带卡里内嵌的世界书。

## 它有哪些开关

**追踪对象**四种模式：仅追踪 `{{user}}` / 仅追踪指定的一位角色 / 追踪指定的多位角色 / 自动给新出现的角色建档。每个对象一份独立档案。

**自动门控**（省 token）：带「自动」徽章的补丁只在条件满足时才发出去。

| 门控 | 管哪些补丁 | 什么时候才发 |
|---|---|---|
| 经期相关 | 生理期体质补丁、经期其他角色反应 | 正在来月经 |
| 孕期相关 | 孕期母体反应、角色认知边界、意识状态演化、血脉遗传特质 | 已经怀孕 |
| 周期模块休眠 | 生理周期模块 | 还没怀孕 |
| 受孕流程 | 怀孕判定模块 | 受精那刻起 → 生完恢复为止 |
| 精子描写 | 精子与受精描写 | 体内还有精子，或已怀孕 |

关掉某一条门控 = 那一类补丁永远发送。

**字段开关**：每个字段都能单独关。关掉之后四件事一起生效：推演不再需要它（省输出 token）、上一轮状态里也不带它、面板上不显示、发给主 API 的摘要里不出现。

**补丁**可以按对象分开写（对象级覆盖全局），有数值的补丁字段直接嵌在卡里。互斥的模块同时打开会在页首给出警告。

**呈现方式**：面板可以只用悬浮窗、插进聊天、或者两边都有；插进聊天时可以停在聊天区里，也可以贴在最后一条消息下面。收起时会变成一台小手机。

**楼层面板**：每个楼层下面都能挂一份**那一楼当时的状态**（历史快照，不是当前状态）。每一楼可以单独标成「不参与推演」。

**骰子**是一张可增删的清单，自己写骰式也行（`1d100`、`2d6`、`1d100+5`），也能锁定当前这组骰池，推演一直沿用直到解锁。

| 骰子 | 用途 |
|---|---|
| D100_1 | 受精判定 |
| D100_2 | 胎数判定 |
| D100_3 ~ D100_6 | 子1 ~ 子4 的性别 |
| D100_7 | 胎数 ≥ 5 的卵生 / 虫族 / 鱼类的整批性别倾向 |
| D5 | 着床天数（1=6天 … 5=10天） |

已锁定的判定结果（受精成功与否、着床日、胎数、性别、致孕方）不会因为骰值变化被推翻。

**插件接口**可以配多套渠道随时切换。也能从酒馆预设导入参数（模型名、温度、max tokens、各种采样、额外请求头 / 体），以及从预设的上百条条目里挑几条打包进插件。

**外观**：面板左下角和聊天里那个 BOT 的头像槽位都能换图，主题能切，悬浮球和面板位置能拖并且记住。

## 它不碰你的东西

- 不改你的酒馆设置，也不会切换你当前启用的预设
- **不会以任何方式改写你的聊天记录**，只在聊天文件里存自己那一份数据
- 不替别的插件改配置；对方没有公开接口的事，它到这儿就停

## 数据存在哪

- **状态数据**：当前聊天的 metadata 里，跟着聊天文件走。换角色卡、开新聊天都不会串。
- **图鉴**：全局设置里一份，所有聊天共用。
- **骰值**：也按聊天独立，这个聊天掷出来的数字不会带到别的聊天去。
- **骰子清单**（有哪些骰子）：全局设置，所有聊天共用一份。
- **设置**（接口、开关、补丁文案、面板位置）：全局，跟着酒馆设置走。

## 导入导出

存档可以导出成文件再导回来，分两条路：

- **仅状态**：把日期换成"距今多少天"来存，换到别的档里也能对上。
- **含时间与日程**：日期原样带走，连日历里的日程一起。

换聊天、换角色、重装插件之前先导一份，比什么都实在。
