# 阶段插图 · 内置图放这里

## 规格（一套图必须一致）

- **画布 1200 x 900**（4:3）
- **底图 = 不透明** ⇒ 铺满整幅
- **其它全部 = 透明底** ⇒ 直接盖在底图上，**不用算任何坐标** ✓
- 格式：**WebP（无损）**。2026-10-18 统一把原来那套 png/jpg 转成了无损 WebP，
  像素一模一样、体积省 29%（插件要上传发布，所以压了 ✓）

## 子宫（透明层，按子宫里的精液量分六档）

| 档位 | 文件名 |
|---|---|
| 空 | `womb_empty.webp` |
| 残留 | `womb_residue.webp` |
| 少 | `womb_low.webp` |
| 中 | `womb_mid.webp` |
| 多 | `womb_many.webp` |
| 满 | `womb_max.webp` |

⚠️ 底图（阴道）那张**本身不带子宫** ⇒ 子宫这一层**每一档都要贴**，
   空的时候也要贴「空」那张（不然整个子宫都不出现）。

## 孕期（透明层，按孕周换）

| 孕周 | 文件名 |

## 换图怎么办

照原名覆盖就行，`src/stages.js` 里那张表不用动。
没画的档位会**回落到最近的已画档**（少的没画就用残留，满的没画就用多）。
